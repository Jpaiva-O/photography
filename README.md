# Paiva Studio — produção expressa

Landing page em português para captação de briefings de saquinhos de pipoca personalizados para eventos.

## Rodar localmente

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

Acesse `http://localhost:8000`.

## Inclui

- Hero com prévia fotográfica do produto e aplicação da logo Copasa;
- fluxo visual de briefing em três etapas;
- formulário de cotação expressa com data e quantidade;
- contador de dias até 01 de setembro de 2026;
- layout responsivo para celular, tablet e desktop.
